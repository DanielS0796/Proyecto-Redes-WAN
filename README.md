## Descripción General

NETFORGE SUITE es una solución académica e interactiva orientada al fortalecimiento de competencias prácticas en redes WAN y administración de infraestructura de telecomunicaciones.

El proyecto integra dos herramientas complementarias desarrolladas mediante tecnologías web y metodologías iterativas asistidas por inteligencia artificial:

- **NetForge PRO Simulator**
- **NetForge Network Configuration Suite**

Estas aplicaciones permiten modelar, calcular, automatizar y simular procesos críticos de diseño, configuración y validación lógica de redes empresariales modernas.

---

# Objetivo General

Desarrollar un entorno digital integral para la simulación, automatización y validación de configuraciones WAN, permitiendo fortalecer competencias técnicas mediante experimentación práctica sin dependencia de infraestructura física.

---

# Herramientas incluidas

## 1. NetForge PRO Simulator

Simulador gráfico avanzado orientado al modelado visual de redes empresariales.

### Funcionalidades

- Creación visual de topologías
- Simulación interactiva de dispositivos
- CLI estilo Cisco IOS
- Routing dinámico
- OSPF
- EIGRP
- BGP
- Configuración de interfaces
- Gestión VLAN
- Exportación SVG
- Simulación de tráfico lógico
- Administración de sesiones concurrentes

---

## 2. NetForge Network Configuration Suite

Suite automatizada para cálculo y generación de configuraciones de red.

### Funcionalidades

- Generación multi-vendor
- Cálculo IPv4
- Cálculo IPv6
- División CIDR
- Cálculo VLSM
- Gestión VLAN
- Constructor de topologías
- Exportación estructurada de comandos

Compatible conceptualmente con:

- Cisco
- MikroTik
- Juniper
- Huawei
- HP Aruba
- TP-Link
